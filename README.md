# DAIBM-SCF Demo MVP

Двуязычный демонстрационный прототип магистерской диссертации: русский интерфейс используется по умолчанию, китайский включается одной кнопкой. Система показывает полный сценарий «заявка → оценка риска → решение → контрольное действие → проверяемая запись».

基于硕士学位论文构建的俄中双语演示原型。系统默认使用俄语，可一键切换中文，完整展示“融资申请 → 风险评估 → 融资决策 → 控制反馈 → 可信审计”的业务闭环。

## Что можно показать / 可以演示什么

- четыре готовые страницы: обзор, оценка риска, аудиторский реестр и методика；
- 业务总览、风险审查、审计账本和模型说明四个演示页面；
- три синтетических кейса с решениями «одобрено / ручная проверка / отказ»；
- 三组匿名合成案例，分别产生“通过 / 人工复核 / 拒绝”结果；
- объяснение вклада каждого фактора риска；
- 可视化解释每个风险因素对结果的贡献；
- хеш-цепочка из четырёх событий на каждую заявку и проверка её целостности；
- 每笔申请产生四类业务事件，并支持哈希链完整性验证；
- создание собственного кейса непосредственно во время демонстрации；
- 答辩现场可录入新的融资案例并立即生成结果。

Готовый трёхминутный сценарий выступления находится в [docs/demo-script.md](docs/demo-script.md)。

完整的俄中双语三分钟演示讲稿见 [docs/demo-script.md](docs/demo-script.md)。

## Быстрый запуск / 快速启动

### Docker

```powershell
docker compose up --build
```

### Python

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-dev.txt
uvicorn app.main:app --reload
```

Откройте / 打开：<http://127.0.0.1:8000>

Нажмите **«Запустить демонстрацию»** / 点击 **“开始答辩演示”**，系统会重置并装载 3 个演示案例和 12 条账本事件。

## API

- `GET /api/dashboard` — показатели демонстрационного контура / 演示指标；
- `POST /api/requests` — расчёт новой заявки / 创建并评估申请；
- `GET /api/requests` — реестр заявок / 申请列表；
- `GET /api/ledger` — журнал событий / 账本事件；
- `GET /api/ledger/verify` — проверка хеш-цепочки / 验证哈希链；
- `POST /api/demo/reset` — сброс и загрузка трёх кейсов / 重置并装载演示案例；
- `GET /docs` — интерактивная документация OpenAPI。

## Проверка / 测试

```powershell
python -m pytest -q
```

Тесты проверяют порядок рисков, обнаружение подмены записи, API-сценарий, три результата решения и повторный запуск демонстрации。

测试覆盖风险排序、账本篡改检测、API 闭环、三类决策结果和演示环境重置。

## Границы MVP / 科研边界

Это компьютерная имитационная проверка сценария, а не промышленная банковская платформа. Текущий реестр — связанная хеш-цепочка поверх SQLite; риск-модель — прозрачный взвешенный базовый алгоритм. MVP не заявляет реализацию Hyperledger Fabric, TGNN, ZKP или интеграцию с реальным банком.

本项目属于计算机模拟场景验证，不是生产级银行系统。当前账本是 SQLite 上的关联哈希链，风险模型是透明加权基线。MVP 不声称已经实现 Hyperledger Fabric、TGNN、ZKP 或真实银行系统集成。

База данных, исходный текст диссертации и реальные данные предприятий не включаются в Git-репозиторий.

运行数据库、论文原文件和真实企业数据不会提交至 Git 仓库。
