# 演示数据集说明 / Demo dataset overview (v1.0.0)

演示数据集把平台的每一类能力都放上真实可点开的数据：正常结清、逾期预警、违约核销三条企业故事，
一个训练出 ACTIVE 模型的历史组合，一个等待审计员激活的 CANDIDATE 模型，以及它们之间的数据快照和决策血缘。

所有数据都是**合成的受控演示数据**（`provenance = CONTROLLED_DEMO`），不对应任何真实企业或真实资金往来。

## 1. 生成方式（冻结）

| 项目 | 说明 |
|---|---|
| 定义 | `app/demo_dataset.py`（`DemoDatasetSeeder`），v1.0.0 起冻结；由 `tests/test_demo_dataset.py` 锁定其结构 |
| 生成路径 | **只调用业务服务**（与用户操作同一条受治理的代码路径）：申请、放款、还款、逾期、违约、结果、预警、任务、快照、模型全部由服务创建，账本、状态转移历史和审计轨迹完整；不直接写表 |
| 触发 | `DAIBM_DEMO_DATASET=true`（Compose 默认）且设置了 `DAIBM_DEMO_PASSWORD` 时，应用首次启动自动生成，约 30 秒 |
| 手动 | `docker compose -p daibm-scf-mvp exec mvp python -m app.demo_dataset` |
| 幂等 | 以合同号 `DEMO-NORMAL-001` 为标记；已存在时返回 `already_present`，重复启动不会重复生成 |
| 关闭 | 生产环境设 `DAIBM_DEMO_DATASET=false` 并清空 `DAIBM_DEMO_PASSWORD`（没有演示账号时不会生成：`demo_accounts_disabled`） |
| 确定性 | 业务内容（企业、金额、风险因素、结果、模型训练样本）每次相同；ID、时间戳和哈希每次不同；到期日相对“今天”计算，所以逾期天数始终是 35 天和 95 天 |

一键展示：`scripts/ops/init-env.sh && docker compose -p daibm-scf-mvp up -d --build`，健康检查通过即可登录演示（2026-09-25 实测：
空数据卷启动到 healthy 32 秒，数据集已就绪）。`scripts/defense_preflight.py` 可只读地检查健康、页面、文档和五个角色登录。

## 4. 历史组合（模型训练用）

- 37 笔 1,000.00 CNY 的历史融资（`DEMO-HIST-001` … `DEMO-HIST-037`，供应商 SUPPLIER-001），全部走完整流程并结清；
- 17 笔违约（逾期 95 天 → 违约 → 核销），20 笔按期还款；违约与基线风险相关，但比基线概率更频繁，校准有真实可纠正的偏差；
- 规则扫描为历史组合生成的 55 条预警都已按流程处理（指派 → 处理 → 解决 → 审计员关闭），状态 CLOSED。

## 5. 模型版本与数据快照

| 模型 | 状态 | 训练快照 | 结果数（违约/未违约） | 时间外验证（70/30） | Brier 前 → 后 | log loss 前 → 后 |
|---|---|---|---|---|---|---|
| `calibration:controlled_demo@v1` | **ACTIVE**（`gate_passed` 自动激活） | 快照 A：包含 32、排除 0 | 32（14 / 18） | 训练 22 / 验证 10 | 0.1386 → 0.0275 | 0.457 → 0.160 |
| `calibration:controlled_demo@v2` | **CANDIDATE**（等待审计员人工激活） | 快照 B：包含 39、排除 0 | 39（18 / 21） | 训练 27 / 验证 12 | 0.1865 → 0.0610 | 0.557 → 0.236 |

- 两个模型都属于 BANK-001，范围 `controlled_demo`；`external_verified` 范围没有激活模型（受控演示数据不能服务真实验证请求，Scope 矩阵会拒绝）。
- v1 训练于前 32 笔历史结果；v2 在此基础上加入 5 笔新历史结果和两家故事企业（稳健制造、西部化工）的结果。
- 快照不可变：记录每条结果的修订号、是否纳入、排除原因与审核状态；模型详情可跳转到其训练快照。
- **决策血缘**：三家故事企业的风险评估都由 ACTIVE v1 校准；在申请详情 → 风险决策中可沿着 决策 → 模型版本 → 数据快照 → 32 条训练结果 追溯。
