# Direction A — TGNN Early-Warning Conference Paper Plan

Status: implementation protocol v1. This document defines a conference rerun and does **not** rewrite the frozen master's thesis or the defence reference artifacts.

## Research question

Can temporal supply-chain graph structure provide measurable early-warning value when the data-generating process contains independently recorded neighbour-to-neighbour risk propagation, and does that value disappear under graph controls?

Core story only:

`dynamic SCF graph -> GCN spatial encoder -> temporal encoder -> risk warning -> propagation/lead-time analysis`

Direction B (AI/blockchain closed loop) is out of scope for this paper.

## Evidence classes

### ORIGINAL_THESIS_RESULT — reference only

The frozen thesis reports, among other results:

- TGNN F1 = 0.87 under the thesis normal-market condition.
- TGNN F1 = 0.68 under the thesis severe-market condition.
- Mean early-warning time on 68 thesis-reported confirmed risk events = 42.3 days for TGNN, versus 21.5 days for GCN and 18.7 days for LSTM.

These values are historical thesis claims only. The original enterprise data/code needed to reproduce them are not available in this repository. They must never appear in a `CONFERENCE_RERUN` result table as newly reproduced values.

### 2026_REIMPLEMENTATION / SYNTHETIC_DEMO — existing defence evidence

The current defence reference path uses `synthetic-scf-v1` and `tgnn-v0.4`. Its synthetic latent-risk process is not generated by neighbour propagation. Its metrics are useful for implementation verification, not for proving a graph-propagation advantage. Existing reference artifacts remain frozen.

### CONFERENCE_RERUN — Direction A only

New experiments use the isolated `research/conference/direction_a` package and `synthetic-scf-propagation-v1`.

## Dataset contract

Each synthetic enterprise is a node. Directed supplier/customer relations are edges with explicit active-month intervals. Each month contains observable node state and edge transaction features. The generator also records hidden causal variables used **only for ground-truth evaluation**, never as model input:

- `propagation_contribution[t, node]`: risk pressure induced by active incoming neighbours at month `t`;
- `propagation_events[t, node]`: severe events whose sampled cause includes the propagation channel;
- `severe_events[t, node]`: union of independently generated and propagated severe events.

The zero-propagation control sets `propagation_strength = 0`; it must produce zero propagation contribution and zero propagation-labelled events. Dataset identity is content-hashed and includes generator configuration and arrays.

This is synthetic mechanism validation. It is not evidence about a real enterprise population.

## Prediction task

For anchor month `t`, models receive only the preceding `window_months` observations and predict whether a severe event occurs in the following `horizon_months` period. Default formal protocol: 12-month history and 3-month horizon. Smoke runs may use smaller windows for speed and are labeled `SMOKE_ONLY_NOT_FOR_PAPER`.

No feature at or after the anchor enters the input. Normalization statistics are fitted on training-period observations only.

## Chronological split and threshold policy

`direction-a-chronological-v1` partitions ordered prediction anchors into train / validation / test blocks (default 60% / 20% / 20%). All train anchors precede all validation anchors, which precede all test anchors.

Classification threshold selection is performed on the validation partition only, maximizing F1 over a predeclared candidate grid with a deterministic tie rule. Test labels or test performance cannot influence threshold selection. ROC-AUC and PR-AUC are threshold-free and reported only when both classes are present.

Class imbalance is handled explicitly. Neural models use training-partition positive weighting; Logistic Regression and Random Forest use balanced training options. The observed event rate for every run must be stored rather than assumed to equal the thesis rate.

## Models

Required comparison set:

1. Logistic Regression — non-temporal graph-free baseline.
2. Random Forest — nonlinear graph-free baseline.
3. BiLSTM — temporal, graph-free baseline.
4. GCN — graph spatial baseline with temporal pooling.
5. TGNN — minimal GCN + BiLSTM.

The conference TGNN uses the true final forward and backward BiLSTM hidden states. It is versioned separately and does not overwrite `tgnn-v0.4` or its ONNX artifact.

## Graph ablations

Formal runs include the observed dynamic graph plus three controls:

- `identity_only`: removes neighbour message passing while preserving the neural path;
- `node_permuted`: applies a seeded node permutation to the graph as a topology-mismatch control;
- `static_first`: repeats the first graph snapshot through the temporal window, removing topology dynamics.

The primary mechanistic claim is conditional: a TGNN advantage is credible only if it appears on propagation-grounded data and degrades under relevant graph controls. Negative or null ablations are retained.

## Cross-industry evaluation

`strict_inductive_leave_one_industry_out_v1` excludes the held-out industry's nodes from both training and validation and evaluates only those nodes in test. This is a synthetic cross-industry transfer experiment. It is not a claim of real-industry generalization.

## Metrics

Per model/run, persist at least:

- ROC-AUC when computable;
- PR-AUC when computable;
- F1, precision, recall, confusion matrix;
- selected threshold and `threshold_source=validation`;
- positive-event rate;
- propagation-ground-truth metrics using `propagation_events`;
- early-warning summary with a frozen definition;
- dataset hash, split version, seed, feature schema, model version, checkpoint hash, run config.

The initial early-warning implementation is an anchor-month descriptive metric over positive future-horizon windows. Before a paper table is frozen, event deduplication and conversion from months to days must be specified and tested. Until then, no new result may be compared numerically with the thesis-reported 42.3/21.5/18.7-day values.

## Formal experiment gate

A smoke run proves only that the pipeline executes. It is not publishable evidence.

Before formal results:

- freeze seed list before inspecting test outcomes;
- freeze market-condition generator parameters before inspecting test outcomes;
- freeze threshold candidates and statistical tests;
- run observed graph and all three graph controls;
- run zero-propagation negative control;
- run leave-one-industry-out transfer for all four synthetic industries with adequate class support;
- retain all failed, zero-denominator, one-class, and negative-result runs in the manifest;
- do not tune the generator merely to force TGNN superiority.

## Current known limitation

The synthetic propagation generator creates causal ground truth by construction. A successful TGNN result would therefore establish mechanism recovery under the stated synthetic process, not external validity. Real-data validation remains `NEED HUMAN CONFIRMATION` until a lawful, documented dataset with label and temporal provenance is available.
